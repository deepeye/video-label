# Step4 时间线右键新增事件设计

> 版本：v1.0 · 2026-06-24  
> 背景：当前 Step4 虽然支持“点模式 / 范围模式 / 右侧新增事件”，但用户仍无法像标注工具那样在时间线某一帧上直接右键发起事件创建，影响“随意选中某帧并新增事件”的直觉体验。

---

## 0. 要解决的问题

当前新增事件入口主要是：

- 右侧 `新增事件`
- 顶部切换到 `点 / 范围` 后，在时间线操作

但这两种方式都不够像“时间线标注工具”的自然交互。用户期望的是：

> 先在时间线某一帧定位，然后通过右键直接发起新增事件。

---

## 1. 已确认目标

用户已确认需要的交互是：

- **时间线区域右键**
- 菜单中提供：
  - `新增点事件`
  - `新增区间事件`
- 选择 `新增区间事件` 后：
  - 右键位置作为起点
  - 再拖出结束位置完成创建
- 这种操作可以连续反复执行多次

---

## 2. 方案选择

采用 **方案 A：时间线右键上下文菜单 + 区间创建进入一次性拖拽态**。

### 点事件流程

- 用户在时间线某处右键
- 弹出菜单：
  - `新增点事件`
  - `新增区间事件`
- 选择 `新增点事件`
- 系统立即在该时间创建一个点事件
- 自动选中该事件，并打开右侧编辑表单

### 区间事件流程

- 用户在时间线某处右键
- 选择 `新增区间事件`
- 系统把右键位置记为 `range start`
- 时间线进入一次性的区间拖拽创建态
- 用户拖动并松手
- 创建区间事件并自动选中
- 退出该临时创建态，恢复普通浏览态

---

## 3. 实现设计

### 3.1 不引入复杂全局状态机

本次不需要上升到全局大状态机，只需要在时间线组件中维护极小的上下文状态。

建议在 `Step4Timeline.tsx` 中增加：

- `contextMenu: { x: number; y: number; timeMs: number } | null`
- `contextRangeStartMs: number | null`

作用：

- `contextMenu`：控制右键菜单显示与位置
- `contextRangeStartMs`：标识当前是否处于“右键发起的区间创建态”

### 3.2 右键菜单只属于时间线

右键菜单只在**时间线轨道区域**触发，不扩散到视频区域或整个 Step4。

这样可以避免：

- 与视频区交互冲突
- 与 marker 点击/拖拽语义打架

### 3.3 右键点事件不依赖当前模式

`新增点事件` 应直接生效，不要求用户先切到顶部 `点` 模式。

也就是说：

- 右键菜单是**独立快捷入口**
- 与现有顶部模式并存

### 3.4 区间事件走“一次性拖拽态”

`新增区间事件` 的重点是：

- 只把这一次创建切入拖拽态
- 不永久改变全局模式

流程：

1. 右键某帧
2. 点击 `新增区间事件`
3. 记录 `contextRangeStartMs`
4. 用户拖动
5. 松手后创建区间事件
6. 清空 `contextRangeStartMs`

所以这是：

> 一次性任务态，而不是新的长期模式。

### 3.5 与现有顶部模式共存

现有顶部模式：

- 浏览
- 点
- 范围
- 区域

应继续保留。

右键菜单只是一个新增入口，不替代它们。

这样用户既可以：

- 用顶部模式做连续标注
- 也可以用右键做点对点快速创建

这是一个**时间线入口增强**。

## 5. 测试要求

### 5.1 右键菜单显示测试

补充以下断言：

- 在时间线右键
- 菜单出现
- 菜单项包含：
  - `新增点事件`
  - `新增区间事件`

### 5.2 右键新增点事件测试

补充以下断言：

- 在某时间右键
- 点击 `新增点事件`
- 系统创建一个点事件
- 自动选中该事件

### 5.3 右键新增区间事件测试

补充以下断言：

- 在某时间右键
- 点击 `新增区间事件`
- 再拖动并松手
- 创建一个区间事件

本次不要求新增 E2E，focused timeline tests 足够。

---

## 6. 非目标

本次改动明确不做：

- 视频区右键菜单
- 右键菜单的多级复杂命令
- 区间事件表单式创建
- 替换现有顶部模式
- 全局上下文菜单系统
- Step5 或其它步骤的联动改造

这是一个**时间线右键创建入口**，不是整体交互重构。

---

## 7. 最终结论

这次增强的本质是：

> 让 Step4 更像一个真实的视频标注工具：先在时间线上选中某一帧，再通过右键直接发起事件创建。

推荐实现为：

- 时间线右键菜单
- 提供 `新增点事件 / 新增区间事件`
- 区间事件使用一次性拖拽态完成创建

这样既保留现有模式入口，又补齐了用户最自然的“在某帧上直接做事”的操作方式。
